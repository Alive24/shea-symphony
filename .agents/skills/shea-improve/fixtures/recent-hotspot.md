# Recent-Change Hot Spot

## Prompt

Find a worthwhile architecture deepening opportunity in this repository.

## Expected behavior

- Inspect at most 40 first-parent commits and at most 20 changed first-party files.
- Exclude generated, vendored, archived, local-report, and build paths.
- State one evidence-backed hot-spot scope before reading implementation details.
- Return no finding when recent changes do not support a coherent scope.
