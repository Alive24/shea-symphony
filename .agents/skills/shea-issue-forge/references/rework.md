# Guarded Rework

Use `issue.rework` only when a live Human Review contract must change after
operator discussion. Prepare a full replacement title/body, preserved review
evidence, explicit Rework direction, and confirmation. Do not use ordinary
promotion or raw Project mutation.

Record evidence before changing state. The transition to Rework is the final
mutation. Read back the replacement contract, current PR/workspace identity,
claim fields, and state. Main resumes the existing canonical workpad and branch,
then stops at Agent Review; Rework never grants Main authority over Human Review.
