# Backlog Notes

Status: Draft

Backlog notes in this directory are not GitHub issues. They are seed material
for later discussion.

Do not treat a note here as executable work until it is promoted through the
normal issue workflow.

## Rules

- Keep notes small.
- Link to the source question, ADR, or doc section.
- Prefer deletion or consolidation over creating a new note.
- Do not write implementation plans before the boundary decision is clear.
