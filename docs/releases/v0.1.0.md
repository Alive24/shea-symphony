# Shea Symphony App v0.1.0

This is the first stable Shea Symphony App release for Apple Silicon macOS and
Windows x64. Each package embeds the `shea-symphony-legacy` compatibility
runtime built from the same release commit. No standalone Shea CLI is
distributed.

## Downloads

- Apple Silicon macOS: `Shea-Symphony-App-v0.1.0-macos-arm64.zip`
- Windows x64: `Shea-Symphony-App-v0.1.0-windows-x64-setup.exe`
- `release-manifest.json`: package and embedded-runtime identities
- `SHA256SUMS`: SHA-256 checksums for the packages and release manifest

Verify the selected package against `SHA256SUMS` before opening it.

## Unsigned first release

This release does not carry an Apple Developer ID signature/notarization or a
Windows code-signing certificate. The macOS bundle is ad-hoc signed only to
preserve its bundle integrity. Gatekeeper or SmartScreen may show the normal
warning for an unsigned download. Review that warning and use the operating
system's visible confirmation flow; do not disable or bypass platform security.

On macOS, extract the zip, move **Shea Symphony App** to an operator-selected
Applications folder, and open it visibly. On Windows, run the NSIS installer
interactively; it defaults to a per-user installation and does not need silent
or elevated installation flags. Launch the App after installation so it can
validate its embedded runtime and publish the machine-local discovery record.

Repository onboarding continues through the global `setup-shea` skill from
this same release. Setup verifies the package, discovery record, embedded
runtime digest and identity, then reconciles repository-owned resources from
the release's immutable commit. Setup never claims an issue or launches an
agent lane.
